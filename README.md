Repo officiel de l'application Kiosky (com.AndroidAiDEV.kiosky).
----
Kiosky est une Application déstinée aux téléphones sous android pour les transformer en Kiosk. Avec chaques bouttons programmables pour avoir un accès simplifié à certaines applications ou pouvoir associer un bouton à une scène spécifique (un peu comme un DeckStream)
Cette Application est dévelopée par AiDEV, sous le nom de projet com.AndroidAiDEV.kiosky. Depuis le 7 Juillet 2026, cette application n'est plus OpenSource, pour éviter les vols.
